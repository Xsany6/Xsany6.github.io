Catatan Penting dan Keamanan:

⚠️ Tautan Google Drive (Office, Firefox, dan ISO OS) mungkin memerlukan login akun Google untuk menghindari batas unduhan.

💿 File ISO dapat di-burn ke DVD atau dibuat bootable USB menggunakan tool seperti Rufus atau Ventoy.

💡 File **.RAR** memerlukan **7-Zip** atau **WinRAR** untuk diekstrak. File **.EXE** dan **.MSI** adalah installer langsung.
